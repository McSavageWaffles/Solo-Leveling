# Client

This directory contains a barebones React Native application using Expo. It currently displays a welcome message and includes simple helper functions to add workouts and meals through the API.

## Running the App

1. Ensure Node.js is installed. Install the Expo CLI globally with `npm install -g expo-cli` or use `npx expo`.
2. Install dependencies and start the development server:
   ```bash
   cd client
   npm install
   npm start
   ```
3. Open the app in the Expo mobile client (or use an emulator) to begin development.
4. Edit `client/api.js` to connect the helpers to your backend server.
